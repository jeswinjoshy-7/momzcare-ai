Return Policy

- Returns are accepted only within the approved return window for eligible items.
- Products must generally be unused, in original packaging, and accompanied by order details unless the case is damage on arrival or wrong item delivery.
- Personal care, feeding, and hygiene items are non-returnable once opened unless there is verified damage or fulfilment error.
- If return eligibility is unclear, the support reply must state that the case needs review and must not promise approval.
- If a customer is missing parts, the support flow may request photos of the package contents and box label before advising replacement or partial resolution.
